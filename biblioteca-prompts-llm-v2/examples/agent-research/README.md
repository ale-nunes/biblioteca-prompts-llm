# Exemplo — agente de pesquisa com fontes

## Objetivo

Pesquisar um tema, comparar fontes e produzir um relatório rastreável, respeitando limites de ferramentas e orçamento.

## Fluxo recomendado

1. Planejador transforma a pergunta em subperguntas.
2. Pesquisador consulta apenas ferramentas autorizadas.
3. Verificador confere se cada afirmação importante é sustentada por uma fonte.
4. Redator compõe o relatório com citações.
5. Revisor checa contradições, lacunas e formato.

Não é obrigatório criar cinco agentes separados: comece como fluxo simples e divida componentes apenas se os testes mostrarem benefício.

## Critérios de conclusão

- Fontes acessíveis e relevantes.
- Afirmações importantes ligadas a evidências.
- Contradições registradas.
- Limitações explícitas.
- Nenhuma ação externa não autorizada.
- Limite de iterações e custo respeitado.
